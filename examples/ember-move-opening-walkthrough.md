# Ember Move Opening Lab Walkthrough

This note is the quickest way to read the extra review model in `ember-move-opening-lab`.

| Case | Focus | Score | Lane |
| --- | --- | ---: | --- |
| baseline | position pressure | 203 | ship |
| stress | move ordering | 131 | watch |
| edge | search width | 199 | ship |
| recovery | endgame risk | 206 | ship |
| stale | position pressure | 112 | watch |

Start with `recovery` and `stale`. They create the widest contrast in this repository's fixture set, which makes them better review anchors than the middle cases.

The useful comparison is `endgame risk` against `position pressure`, not the raw score alone.
